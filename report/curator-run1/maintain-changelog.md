---
name: maintain-changelog
description: Use when documenting changes made to the codebase in the CHANGELOG.md file.
---
1. Open the CHANGELOG.md file in the root of the project.
2. Locate the section titled '## Unreleased'.
3. For each change made (bug fixes, new features, etc.), add a bullet point in the format: '- fix(<function name>): <short description>'.
4. Ensure that at least three bullet points are added for each set of changes.
5. Review the entries for clarity and conciseness.
6. Save the changes to the CHANGELOG.md file.
7. Commit the changes with a message indicating updates to the changelog.
8. Push the changes to the repository.
9. Verify that the changelog is correctly formatted and reflects all recent changes.
